# 前端产品说明

## 产品目标

界面服务于不懂编程的网球教练、场馆人员和甲方验收人员。用户不需要理解模型、阈值或命令行，
只需完成“选择视频 → 等待分析 → 查看复盘”三步。

## 核心流程

1. 首页只保留一个主任务：上传比赛视频。
2. “真实比赛样例”直接使用冻结算法产物，演示数字全部从 `scene3d.json` 计算。
3. 分析过程使用四个中文阶段解释当前进度，不向用户暴露内部模块名。
4. 报告先给结论和关键数字，再提供视频、事件、落点图、三维视图和可信度说明。
5. 点击任意事件即可跳到对应视频时刻；分析标记可随时开关。
6. 顶部“冻结模型 · 纯推理”表示上传期间不会训练或改变 BallNet 参数。

## 可视化约定

- 近端球场始终位于落点图下方，远端位于上方。
- 界内落点使用荧光绿色；界外落点使用红色叉号。
- 落点图只展示落点，不叠加轨迹线。
- 界内率、最常落区、平均底线距离、轨迹覆盖率均来自真实分析文件。
- 三维视图中的界外球不点亮任何场内区域，只保留落点标记。

## 输入约定

- 不限制用户上传帧率；24、25、29.97、30、50、60、120fps等有效原生帧率均可分析。
- 29.97/30fps只是回归验收基线。高帧率包含更多高速运动与触地瞬间，但逐帧计算量也会按比例增加。
- 不通过人工插帧制造检测证据；高帧率必须来自相机原始素材。
- 推荐固定高位底线机位、横屏、1080p 或更高分辨率。
- 浏览器支持 MP4、MOV、WebM 和 MKV，单文件上限 4GB。

## 维护边界

算法边界记录在 `docs/CURRENT_ARCHITECTURE.md`。常规前端迭代只允许修改 `web/`、展示文案、
只读报告和可视化资源，不得调整跟踪、轨迹、落点或规则判断。
