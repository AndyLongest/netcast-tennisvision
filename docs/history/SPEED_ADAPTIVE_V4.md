# V4 球速自适应搜索（30fps）

## 规则

1. 使用最近两次真实观测位置除以帧间隔，得到图像速度；与 Kalman 速度按 75%/25% 融合。
2. 用该速度从上一状态外推下一帧搜索中心，而不是只围绕上一帧原位置搜索。
3. 当前 720p 样例的第一层半径为 `max(36px, 16px + 0.65 × speed_px_per_frame)`；
   后续层逐级扩张并受物理位移上限约束。
4. 从最后真实观测到新候选计算候选速度。若单帧速度变化超过
   `max(72px/frame, 1.75 × 原速度 + 24px/frame)`（720p），候选被拒绝。
5. 门限为击球和触地反向保留余量，主要拦截误检造成的速度爆炸。

## 同片段实测

- 输入：1280×720，29.9139fps，1,737 帧。
- 有轨迹位置：1,184 帧，与 V3 相同。
- 直接观测：856 帧，与 V3 相同。
- 遮挡预测：328 帧，与 V3 相同。
- 扩圈关联：55 次降至 49 次，部分高速运动由第一层动态半径直接覆盖。
- 11 项追踪回归检查全部通过。
