# V3 自适应搜索实验报告（30fps）

样例输入：1280×720，29.9139fps，1,737 帧。V2 是冻结基线，V3 是本次实验版。

| 指标 | V2 | V3 |
|---|---:|---:|
| 有轨迹位置 | 1,184 | 1,184 |
| 真实观测 | 883 | 856 |
| 遮挡预测 | 301 | 328 |
| 未获得轨迹 | 553 | 553 |
| 扩圈后成功关联 | 未导出 | 55 |
| 球网持续失联终止 | 未导出 | 1 |
| 画面边缘外飞终止 | 未导出 | 1 |

V3 与 V2 共有 844 帧真实观测；V3 新增 12 帧真实观测，同时把 V2 的 39 帧观测改为
遮挡预测。最大差异发生在 31.5–32.3 秒：V2 接受了一串置信度约 0.01–0.06、跳到场外
很远的候选，V3 因物理不可达而拒绝。因而“真实观测帧数”下降不能直接解释成识别质量下降。

本次没有独立人工逐帧真值，所以暂不把 V3 提升为新的阶段最优版。保留 V2 基线，同时提供
V2/V3 同步对照视频，由人工先判断这 39 帧属于漏球还是旧版误检，再据此调节运动门限。
