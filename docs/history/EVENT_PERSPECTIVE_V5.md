# V5 事件感知与透视搜索实验（30fps）

## 实现

- 正常飞行：最近两次真实观测估速，Kalman 主路径优先。
- 触地救援：球向下、位于球场投影内且主路径关联失败时，增加衰减反弹分支；命中后重置速度。
- 击球救援：球进入球员框与球拍扩展区、主路径关联失败、候选明确反向且置信度至少 0.30 时，
  才允许击球分支接管；事件后 6 帧冷却，避免连续重置。
- 透视椭圆：通过每帧球场单应性计算局部横纵米/像素，搜索轴随远近变化，不再使用等半径圆。
- 抑制香蕉轨迹：真实观测是平滑器硬锚点；非触地/击球状态下的极端转弯候选才会拒绝。
- 安全顺序：原 Kalman 主路径能关联时事件模型不得竞争；事件模型只作为主路径失败后的救援。

## 当前样例结果

输入为 1280×720、29.9139fps、1,737 帧。V5 得到 1,160 个轨迹帧，其中 839 个直接
观测、321 个遮挡预测；逐帧标记 11 次 `player_hit` 救援和 8 次 `bounce` 救援。

V4 为 1,184 个轨迹帧、856 个直接观测，因此 V5 暂不提升为阶段最优版。V5 的价值是验证
事件分支和透视椭圆已真正进入逐帧管线；下一步应针对人工指出的具体击球时间窗口调节事件门限，
而不是用全片总数猜测。
